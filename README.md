Nazarik Playtime 2 is a tower defense game made for my friend's birthday. 

All the art and five levels were created in ~2 weeks. 
Development was fast thanks to the composition root approach which prevented many initialization order bugs and made component dependencies clear

If you want to try this game out, visit [itch page](https://mav-666.itch.io/nazarikplaytime2).
